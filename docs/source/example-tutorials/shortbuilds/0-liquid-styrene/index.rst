Liquid Styrene (no polymerization)
==================================

This tutorial illustrates the simplest possible use of ``htpolynet run``:
generating a densified liquid of a single small molecule (styrene), without
any polymerization step.  It is numbered ``0`` because no curing happens —
think of it as a warm-up that exercises the input-generation,
parameterization, and densification stages on their own.
